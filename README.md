# 📌 Overview

**CodeArena** is a full-stack coding platform inspired by online judges like LeetCode.

It provides a secure environment where users can solve programming problems, while administrators can create, manage, and organize coding challenges with video solutions.

The project follows modern software engineering practices with secure authentication, role-based authorization, REST APIs, Redux state management, and responsive UI.

# ⚙ Installation

## Clone Repository

```bash
git clone https://github.com/yourusername/codearena.git
```

## Backend

```bash
cd backend

npm install

npm run dev
```

## Frontend

```bash
cd frontend

npm install

npm run dev
```

---

# 🔑 Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=3000

MONGO_URI=your_mongodb_connection

JWT_SECRET=your_secret

NODE_ENV=development

CLIENT_URL=http://localhost:5173
```
